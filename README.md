# Personal Portfolio Website

A responsive portfolio site built from scratch with HTML, CSS and JavaScript — my first frontend project as part of the codekrafters recruitment task.

## What's inside

- About Me
- Skills
- Projects
- Achievements
- Contact

Fully responsive (mobile + desktop) with small UI touches like hover states, smooth scroll navigation, and a subtle pulse animation on the "available" indicator.

## Tech used

- HTML5 for structure
- CSS3 (custom properties / variables, flexbox, grid, media queries) for styling
- Vanilla JavaScript for scroll behavior — no frameworks, no libraries

## File structure

```text
portfolio/
├── INTRO WEBSITE.html  # page structure and content
├── style.css           # all styling
└── script.js           # smooth-scroll interaction
```

## Running it locally

No build tools or server needed. Just clone the repo and open `INTRO WEBSITE.html` in a browser:

```bash
git clone https://github.com/lohitharjun/My-introduction-website.git
cd portfolio
open "INTRO WEBSITE.html"   # or double-click the file
```
